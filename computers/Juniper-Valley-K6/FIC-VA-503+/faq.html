Q2 How do I install Windows 98?

Follow the steps below:

  • Go into BIOS, Load Setup Default and enable USB Controller.
  • Install Win98 on your system.
  • Download and install the VIA IRQ Routing driver from VIA driver page
  • If you are using an AGP card, install the latest VIA AGP driver, which can be acquired at VIA driver page ( note: If you update the graphic card's driver, you must reinstall the VIA AGP driver)
Q3 How can I make my computer work with Voodoo3 and TNT2 AGP graphic card?

Follow the steps below:

  • Update your BIOS to the latest version, (Read Q12 for latest BIOS info.)
  • Install VIA AGP driver, which can be acquired at VIA driver page
  • Install the driver provided with your graphics card.  (Note: If you update the graphic card's driver, you must reinstall the VIA AGP driver)
Q4 What can I do to make my Diamond G460 AGP card work properly?

Follow the steps below:

  • Update your BIOS to the latest version, (Read Q12 for latest BIOS info.)
  • Update your Diamond graphics card BIOS to version 118
  • Install the driver provided with your graphics card
  • Install VIA AGP driver, which can be acquired at VIA driver page
  • If your PCB No. is 1.0, 1.1A, or 1.1B choose "normal" mode instead of "turbo" to prevent overheat on i740 chip. The PCB No. is printed on the corner of the board, along the last ISA slot.  (Note: If you update the graphic card's driver, you must reinstall the VIA AGP driver)
Q5 Is the VA-503+ compatible with UDMA66 Hard Drive?

Yes, it is compatible with UDMA66 Hard Drive but it can only run as UDMA33.  Please upgrade the BIOS when you use UDMA66 Hard Drive.

Q6 What are the differences among the revisions of VA-503+?

  • VA-503+ rev. 1.0 - Supports 66, 75, 83, & 100 MHz bus
  • VA-503+ rev. 1.1A - Same as rev. 1.0 with  improved EMI
  • VA-503+ rev. 1.1B - Supports 66, 75, 83, 95, 112, & 124 MHz bus
  • VA-503+ rev 1.2A - Same as rev. 1.1B, with improved AGP
  • VA-503+ rev 1.2A with "E-O037" sticker
    • Certified by AMD to support the complete line of K6, K6-2, and K6-III CPU's, except K6-2/533MHz.

Q8 How can I prevent my CD-ROM from stalling during audio playback in Windows 98?

Select your CD-ROM in Device Manager and uncheck the DMA option.

Q9 How can I prevent Windows 95 from displaying a ghost drive when I install a LS 120 drive?

Install VIA IDE BusMastering ver. 2.1.31 or later versions, available at VIA driver page .

Q10 In Windows 95, I have a yellow question mark for PCI Bridge under device manager, how can I correct this?

Follow the steps below:

  • Install VIA INF driver, available at VIA driver page
  • Goto Device Manager , select the PCI Bridge with the question mark, click the Remove button and, then click the Refresh button.
Q11 In Windows 95, I have a yellow question mark for PCI IDE controller under device manager, how can I correct this?

Follow the steps below:

  • Click the Start button on the task bar
  • Select Run, and type in "regedit" in the Open option, then click OK
  • In the left column, double click on the following folder:   \HKEY_LOCAL_MACHINE\System\CurrentContolSet\Services\VxD
  • If you see "NO IDE" in the right column, delete it and then restart your system
Q12 What is the latest BIOS for my board?

The BIOS you use depends on the PCB No. of your board. This number is printed on the corner of the board, along the last ISA slot.


Q13 Does the VA-503+ work with the STB Velocity 4400 AGP card?

Yes, we have tested successfully with the following settings:

  • VA-503+ rev. 1.2A
  • BIOS version 115JE33 or later
  • Aperture Size at 64MB and 128MB
Q14 What Aperture setting should I use for the STB Velocity 4400 AGP card?

If you use STB latest driver version 1.52, set the aperture to 64MB. For more info. read STB FAQ page at  www.stb.com/tech/faqs/v4400faq.html. To download their driver visit www.stb.com/drivers/velocity/vl4400.html

Q16 Why do I get error messages when I install Win95 OSR2, OSR2.1, and OSR2.5 with AMD K6-2 350 and above?

When you are starting Windows 95 OSR2, OSR2.1, or OSR2.5 on a computer with an AMD-K6-2 processor running at speeds of 350 MHz and above, you may receive one of the following error messages:

  • Device IOS failed to initialize.
  • Windows Protection Error.
  • You must reboot your computer.

You need to install the patch provided by AMD. To learn more about this issue visit AMD at: www.amd.com/products/cpg/k623d/win95_update_k6.html

Q17 Which version of the VA-503+ can support the complete line K6, K6-2 and K6-III CPU's?

The VA-503+ rev.1.2A with "EO037" sticker can support the complete line of K6, K6-2, and K6-III CPU's, except K6-2/533MHz. You can find the ECN number printed on a white sticker along the edge of the board or on the gray sticker outside of the box (i.e. E:4503). All boards with a sticker that states,"EO037 " on the board and outside the box can also support the above CPU's.

Q18 Can the earlier release of the VA-503+ 1.2A support the K6-2 /400MHz and above?

The earlier revisions of the VA-503+ 1.2A will only support up to the K6-2 /400MHz.

Q19 How can I distinguish the VA-503+ 1.2A boards that can support the complete line of K6, K6-2, and K6-III CPU's?

There are 3 ways to identify the VA-503+ 1.2A that supports the new K6-2 and K6-III CPU's, except K6-2/533MHz.

  • Look for a white sticker along the edge of the board that has "4503" printed on it. This is the ECN sticker.
  • Look for a gray sticker outside of the box that display "E:4503". This is also the ECN munber.
  • On future boards, look for a sticker that states, "EO037" on the board or outside the box.

Only boards with these stickers are certified by AMD

  Q20 Where can I find the ECN number for the VA-503+?

You can find the ECN number printed on a white sticker along the edge of the board or on the gray sticker outside of the box (i.e. E:4503)

Q21 How to upgrade the motherboard to VA-503+ without format the Hard Drive under Windows 95/98?

Follow the steps below:

  • Copy all the *.cab files to local hard drive from the Windows CD.
    (Note: To copy files from Windows CD, use windows start up disk with CD-ROM driver)
  • Remove the IDE Controller under Device Manager.
  • Replace/Upgrade the motherboard to VA-503+ and change the appropriate jumper setting.
  • Locate the drivers on *.cab files folder you just copied from the CD.
Q22 Why can't I dial out with my PCI modem and there is not yellow question mark under Device Manager?

Follow the steps below:

  • Go into the BIOS, select PNP/PCI Configuration and set the PNP OS Installed to "NO".
  • Download and install the VIA IRQ Routing driver from VIA driver page

Q24 Can VA-503+ supports AGP 4X video card?

The VA-503+ supports AGP 1X and 2X mode only but you can use 4X also because most of the 4X AGP cards are backward compatible.

Q25 Why can't my system shut down properly?

This is a problem only happens on the AT power supply, so please update the BIOS to JP4329. ATX power supply should be fine.

Q26 Does the VA-503+ support AMD K6-2+ CPU?

No. The VA-503+ is designed for desktop CPUs, So it does not support AMD mobile CPUs.
