# Asus PVI-486SP3 Motherboard

![front](front.jpeg)

The PVI-486SP3 is a Socket 3 486 motherboard with ISA, VLB, and PCI slots, and onboard IDE, floppy, serial, parallel, and PS/2 mouse ports.

## Personal Notes

I bought this motherboard from a friend in the [DFW Retro Computing](https://www.facebook.com/groups/350060128451803) Facebook group in February 2025 along with the [Am486DX2-66](../AMD-Am486DX2-66/README.md) CPU installed in it.
